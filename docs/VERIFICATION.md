- 犬や背景が写実的だったため、デフォルメ比率・輪郭・塗りを参考画像に合わせて再制作。
- 8匹の2列表示でタップ領域が重なる問題を、サイズと配置間隔の調整で修正。
- スマートフォンで着せ替え・コレクションへの入口が足りなかったため、ホームと仲間詳細へ追加。
- 本番プレビューの静的ファイルに付くVaryヘッダーが原因で、オフライン時にJS/CSSのキャッシュ照合が失敗していた。自身の同一オリジン静的キャッシュのVary照合を省略し、実際のオフライン起動を再検証して成功。

## 検証の範囲と残る制作

- スマートフォンはChromiumの360pxエミュレーション。iOS Safari・Android実機・PWAの端末別インストール操作は未検証。
- 犬は静止イラストにCSSと記号を重ねた簡易リアクション。独立した8表情や歩行フレームの正式素材は未制作。
- 衣装はオーバーレイ、壁紙・床は色調と模様による簡易表現。犬ごとに元のバンダナを消す編集、壁と床が独立した本格的な部屋背景は未制作。
