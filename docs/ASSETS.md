# TINTALE アセット管理

## 採用素材

制作方法：Codex内蔵 imagegen。追加APIキーは使用していません。

参照：ユーザー添付のTINTALEコンセプト画像。参照画像を直接入力した第2稿を採用しています。写実的だった第1稿は使用していません。

|ファイル|内容|利用側|
|---|---|---|
|`public/assets/atelier.png`|明るい花と木家具のアトリエ|`.room-art`|
|`public/assets/dogs.png`|4列×2行の8匹の透過スプライト|`Dog`コンポーネント|
|`public/assets/items.png`|4列×4行の家具・衣装透過スプライト|`ItemArt`コンポーネント|
|`public/icon.svg`|ボトル型アプリアイコン|PWAマニフェスト|

犬の順序：上段ソラ／レオ／チャイ／ミル、下段ココ／ルナ／ハル／モカ。表示名・犬種・位置は `src/data/catalog.ts` で管理します。描画用の犬種別衣装オフセットは `src/styles.css` の `.breed-*` で調整できます。

アイテムの順序：赤いリボン／青い首輪／麦わら帽子／花飾り、パーカー／王冠／ベッド／ソファ、クッション／カーペット／テーブル／観葉植物、ぬいぐるみ／おもちゃ箱／壁紙／床。壁紙3種は同じ見本に別の色調を適用する簡易表示です。

## 最終プロンプトセット（再制作時の基準）

共通：添付画像を唯一の原典とし、絵本調のかわいい2Dゲームイラストを忠実に再現。柔らかいブラウンの輪郭、明るいパステル、丸く簡略化した形とやさしい水彩風の塗り。写真、写実的な毛並み、細密な木目、長いマズル、現実的な犬の頭身は使用しない。

### キャラクター

添付画像の中央段8匹を忠実に再現。2〜2.5頭身、大きい丸い瞳、短いマズル、丸い頭、小さい体、短い脚。4列2行で全身座り姿、各セル中央、完全透過背景、文字や枠なし。上段は赤バンダナの茶黒ダックスフントのソラ、大きな立ち耳と青バンダナのコーギーのレオ、青バンダナの柴犬チャイ、ピンクリボンの白いふわふわ犬ミル。下段は緑リボンのトイプードルのココ、灰白のハスキーのルナ、大きい耳と花飾りのチワワのハル、ピンクリボンのふわふわポメラニアンのモカ。ソラは参照の左上と紹介欄の顔・耳・色・赤バンダナを維持。

### 背景

参照画像の左下お部屋づくりと右上アトリエを基準にする。横長1536×1024。中央から右寄りの大きなアーチ窓、水色の空と花のお庭、左に木の棚・本・花鉢・色付き瓶、右奥に丸いクッションのクリーム色ソファ、木の梁とつた。下半分は犬を置ける広い明るい木の床とピンクの花柄ラグ。暖かいクリーム・桃色・黄土色。犬・人物・文字・UIは含めない。写真のようなレンダリングは避け、参照のデフォルメと明るさを維持。

### アイテム

参照の下段家具・着せ替え欄のタッチを再現。4列×4行、透明背景、等間隔、重なりなし、文字なし。上記16アイテムを順番通りに配置。赤リボン、青首輪、青リボンの麦わら帽子、デイジーの花、青パーカー、ピンクの宝石の金冠、緑クッション入りベッド、クリームソファ、水色クッション、ピンクの花柄ラグ、短い木テーブル、テラコッタ鉢の植物、くま、ボール入りかご、花柄壁紙、木の床。丸みのある簡略化した輪郭、パステルの水彩風陰影、写実的な木目・毛並みなし。

## 正式素材への置き換え

現素材は、コンセプト画像を参照した生成素材です。ゲーム上の動作検証用として組み込んでおり、ユーザーの最終アート承認済み素材とは扱いません。表情と歩行は別スプライトへ拡張できるよう `Dog` の引数を分けています。現状は8種類の記号・姿勢変化による簡易リアクションで、独立した8表情イラストではありません。

画像を置き換える場合は同じアトラス順序を守るか `Dog` / `ItemArt` のマッピングを更新してください。変更後は `npm run build` でPWAのキャッシュバージョンも更新されます。
