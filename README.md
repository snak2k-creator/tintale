# TINTALE（ティンテイル）

**色をそろえて、心を満たす。**

ソラと色をそろえ、8匹の犬たちと暮らすブラウザゲーム。無料・ログイン不要・サーバー不要です。

## 起動

Node.js 22.12以上（開発検証は24.19）を使用します。

```powershell
npm ci
npm run dev
```

表示されたローカルURLを開いてください。`あそぶ.cmd` をダブルクリックしても起動できます。

```powershell
npm run build       # 型チェック・本番ビルド・オフラインキャッシュ生成
npm run preview     # ビルド済みゲーム / PWA の確認
npm test            # ゲームロジック・100問の解答経路・保存・報酬テスト
npm run test:e2e    # ChromiumでPC/360px幅を操作
```

初回はPlaywrightに対応するChromiumが必要です。未導入なら `npx playwright install chromium` を実行してください。

## あそびかた

1. 「ソラとはじめる」でステージ1へ。
2. 注ぎ元の瓶、注ぎ先の瓶を順にタップします。
3. 空の瓶か、最上段が同じ色の瓶に、1層だけ注げます。
4. 使用する全色を、それぞれ4層の瓶にそろえるとクリアです。

Undo・ヒントは無制限。時間制限はありません。星3の目安以内なら星3、目安の1.5倍（切り上げ）以内なら星2です。目安は保存された解答経路の手数で、最短手数とは限りません。

## 実装内容

- 100問の固定ステージ。8段階の難易度（3〜10色・瓶5〜12本、空き瓶は常に2本）、全問に検証済みの合法解答経路。61問目からは、上の色をどけるまで下の色が「？」で隠れる「ひみつの色」ステージ。
- スマホ幅（720px以下）では1列レイアウトと画面下のタブ、PCでは左メニューの横並びレイアウトで表示。
- 1層ずつ注ぐ操作、連打ガード、Undo、リスタート、Web Workerによる現在盤面からのヒント、一時停止。
- 8匹の仲間・指定ステージでの解放・歓迎演出。ホームでは、いっしょに過ごすなかまを1匹選ぶ（選んだ子がパートナー）。
- 着せ替え13種（うち3種はマスター・ミステリー・レジェンド制覇のごほうび）、壁紙5種、床5種。
- 仲良し度、タップ反応、簡易移動・昼寝・追いかけっこの定型イベント。
- 初回30、星2累計40、星3累計60コイン。評価更新時は差額のみ。
- 8家具。家具は3スロットに配置。
- ミッション、仲間・衣装・家具図鑑、実績、JST基準のデイリーチャレンジ。
- デイリーは検証済み固定問題から日付で選択し、報酬はその日1回50コイン。
- バージョン2のLocalStorage保存、途中盤面とUndo履歴の復元、JSON書き出し・読み込み。
- 効果音・BGM・動き軽減・色の記号表示。
- PWAマニフェストと本番ビルド時生成のService Worker。初回のキャッシュ完了後はオフラインで遊べます。

## アセットと仕様上の境界

添付コンセプト画像を参照して生成したイラストを使用しています。写実的だった初稿を採用せず、丸い顔・短い脚・大きな瞳・柔らかな輪郭の絵本調へ修正しました。アセットの扱いと再生成用指示は [docs/ASSETS.md](docs/ASSETS.md) に記載しています。

**現時点の表現は、静止イラスト＋CSSの簡易アニメーションです。** 8種のリアクションを記号・姿勢・動きで表現していますが、犬ごとの描き下ろし8表情・歩行フレームは未制作です。衣装は元のバンダナ等を消す方式ではなく重ねる方式です。壁紙・床は元の背景への色調／模様のオーバーレイであり、独立した部屋背景の差し替えではありません。ここは正式素材制作で拡張する対象です。

セーブはこの端末・ブラウザだけに保存されます。ブラウザのデータ削除で消えるため、設定からバックアップを保存できます。端末間同期・時計操作への対策・クラウド機能はありません。保存エラーは画面に通知します。PWAのインストールUIはブラウザによって異なり、実機iOS/Androidでの検証は別途必要です。

## 構成

|場所|役割|
|---|---|
|`src/game/puzzle.ts`|合法手、1層移動、完成判定、DFS解答探索|
|`src/data/stages.json`|固定100盤面と合法解答経路|
|`scripts/generate-stages.mjs`|再現可能な候補生成・ソルバー検証・経路保存|
|`src/game/progression.ts`|報酬、解放、購入、装備、保存スキーマ検証|
|`src/game/store.ts`|ZustandとLocalStorage|
|`src/game/atelier.ts`|性格・家具・仲良し度を反映した定型行動|
|`src/game/hint.worker.ts`|メイン画面を止めないヒント探索|
|`src/game/audio.ts`|Web Audioによる効果音とオルゴール風BGM|
|`src/components.tsx`|交換可能な犬・アイテム・瓶の描画|
|`src/App.tsx`|画面・ダイアログ・操作制御|
|`scripts/build-offline.mjs`|ビルドに一致するオフラインキャッシュ|

推奨スタックを踏まえ、サーバー機能のないローカルゲームに適したVite / React / TypeScript strict / Zustandを採用しました。Firebase・外部API・有料サービスは使用していません。変更を依頼されたときは、関連するテストと本番ビルドを実行したうえで、コミットをGitHubリポジトリの `main` に反映します。ブランチ保護で直接反映できない場合は、必要なチェックを通したPull Requestを作成・マージします。リポジトリの公開範囲は、明示的な依頼がない限り変更しません。
